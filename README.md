# Zephyr2318.github.io

Personal homepage of Yuhao Wang — plain HTML/CSS/JS, no build step.

- `index.html` — all content
- `styles.css` — console-style theme (light/dark)
- `scripts.js` — dark-mode toggle
- `assets/images/avatar.jpg` — portrait (falls back to "YW" initials if missing)

Deploy: push to the `main` branch of the `Zephyr2318.github.io` repository, then
Settings → Pages → Source: "Deploy from a branch", `main` / `(root)`.
